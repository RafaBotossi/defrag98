# Defrag98 — pacote inicial

Este pacote contém a especificação inicial para implementar o projeto com Codex, Claude ou outro agente de desenvolvimento.

## Arquivos

- `projeto.md` — visão, arquitetura, MVP, áudio, simulação, UX e roadmap.
- `agents.md` — papéis de agentes/subagentes, fluxo de revisão, QA e regras Git.

## Prompt inicial sugerido

```text
Leia projeto.md e agents.md integralmente.
Atue primeiro como Orchestrator.
Crie o projeto React + Vite + TypeScript e implemente apenas a Fase 1 do MVP.
Antes de avançar para áudio, deixe a engine Canvas funcional, fluida e separada da UI.
Use os papéis definidos em agents.md para revisar a implementação.
Não faça commit, push, merge ou alterações destrutivas no Git sem minha autorização.
```
